# mool a day — mool 하루 휴가

**바로 해 보기: https://yodakrkids.github.io/mool-web/**

작은 섬에서 하루 쉬어 가는 웹 힐링 앱이에요. 점수도 경쟁도 없이, 파도 소리를 들으며 천천히 시간을 보내요.

- **섬에서 쉬기**: 모래사장을 걷고, 조개를 줍고, 썬베드에 눕고, 모닥불 앞에 앉아 불멍. 꼬치를 구워 먹고 바다에 뛰어들기도 해요.
- **낚시와 도감**: 방파제 끝에서 낚시하고, 모은 조개·물고기는 도감에 쌓여요.
- **흐르는 하루**: 새벽·낮·노을·밤이 실제 시간처럼 바뀌고, 맑았다 흐렸다 날씨도 변해요.
- **섬 여행**: 헬기나 카약을 타고 모래톱·바위섬·검은모래섬(온천)·등대섬으로. 돌고래 무리, 갈매기, 게가 섬을 채워요.
- **공유**: 지금 화면을 찍어 SNS에 올리면, 링크를 연 사람도 같은 섬·같은 자리·같은 시간에서 시작해요.
- **이어하기**: 따로 저장할 필요 없이, 다시 열면 마지막 그 자리에서 이어져요.

> A tiny island, the sound of waves, a day off. A relaxing web app with no scores and no rush — walk the beach, fish off the breakwater, sit by the campfire, and watch dawn turn into night.
